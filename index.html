Smart Chinese gender

NEW

Chinese writes 他 and 她 the same sound, so translators often call every character “he”. This detects each character's gender from 她/他, titles like 师姐 / 公子, and name cues — then uses she/her for women and he/him for men in the English translation. Add corrections below.

Skip words / punctuation

Comma-separated words or symbols never read aloud. Type names like comma, period, semicolon, dash, quotes. Only the audio changes.

Pronunciation fixes

Say words the Chinese way — Xin → Shin, Xiao → Shiao, Qi → Chi, Zhang → Jang, Cai → Tsai. Combined names like Qingcheng split automatically. Only audio changes.
